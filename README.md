# Proyecto-Videojuego
# Titulo del juego: Leyendario 
# Descripción del proyecto

# Leyendario es un videojuego de aventura inspirado en la riqueza cultural, histórica y mitológica del Ecuador. El jugador asume el papel de un joven aventurero que debe explorar diferentes escenarios relacionados con el patrimonio ecuatoriano, enfrentarse a criaturas y personajes legendarios, superar desafíos y recuperar lugares históricos.

# Objetivo del videojuego

# Promover el conocimiento y la valoración del patrimonio cultural ecuatoriano mediante una experiencia interactiva que combine aventura, exploración, desafíos y aprendizaje.

# Características principales

# - Exploración de escenarios inspirados en sitios patrimoniales del Ecuador.

# - Enfrentamientos contra criaturas y personajes legendarios.

# - Sistema de habilidades y recompensas.

# - Obstáculos, desafíos y acertijos.

# - Reconstrucción de lugares históricos.

# Estilo visual

# Estética 3D Low Poly, con elementos inspirados en las culturas ancestrales del Ecuador, una ambientación fantástica y una paleta de colores morados, dorados y cálidos.
